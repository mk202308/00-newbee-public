

## Open WebUI + Vault as MCP 연결하기

Open WebUI v0.11.0은 **Sub-agents**와 **도구(Tools)** 기능이 크게 강화되었습니다. Vault as MCP를 Open WebUI의 MCP 서버로 등록하면, AI 에이전트가 옵시디언 볼트를 직접 조작할 수 있습니다.

### 1단계: SSH 터널링 설정 (MacBook → OCI 서버)

Open WebUI가 MacBook의 Vault as MCP에 접근하려면 터널이 필요합니다.

bash

복사

다운로드

\# MacBook에서 실행 (OCI 서버로 터널 생성)
ssh \-R 8765:localhost:8765 ubuntu@\[OCI\_SERVER\_IP\] \-N \-f
\# 또는 OCI 서버에서 실행 (MacBook으로 터널 생성)
\# OCI 서버에서:
ssh \-L 8765:localhost:8765 admin@\[MACBOOK\_IP\] \-N \-f

> 💡 **팁**: `-f` 옵션으로 백그라운드 실행, `-N`으로 명령어 없이 터널만 유지

### 2단계: Open WebUI에서 MCP 서버 등록

1. **Open WebUI 접속**: `http://[OCI_SERVER_IP]:8090`
2. **관리자 패널** → **설정(Settings)** → **MCP 서버(MCP Servers)**
3. **"Add Server"** 버튼 클릭
4. 다음 정보 입력:

| 항목 | 값 |
| --- | --- |
| **이름** | `Vault as MCP` |
| **URL** | `http://localhost:8765/mcp` (SSH 터널링 사용 시) |
| **전송 방식** | `HTTP` |
| **헤더** | (Bearer Token 설정 시에만) |

### 3단계: 연결 테스트

Open WebUI에서 MCP 서버 연결을 테스트합니다.

1. **"Test Connection"** 버튼 클릭
2. **"Get Tools"** 버튼 클릭 → Vault as MCP가 제공하는 도구 목록 확인
3. 정상 연결 시 아래와 같은 도구들이 표시됨:

text

복사

다운로드

📚 Vault as MCP Tools
\- read\_note: 노트 내용 읽기
\- search\_notes: 의미 기반 검색
\- list\_notes: 전체 노트 목록
\- create\_note: 새 노트 생성
\- update\_note: 노트 수정
\- rename\_note: 노트명 변경
\- delete\_note: 노트 삭제




## ⚡ NVIDIA NIM → Open WebUI 연결하기

### 1단계: Open WebUI 관리자 패널 접속

1. **Open WebUI** 접속: `http://[OCI_SERVER_IP]:8090`
    
2. 좌측 상단 **프로필 아이콘** 클릭
    
3. **관리자 패널(Admin Panel)** 선택
    
4. **설정(Settings)** → **외부 연결(Connections)** 메뉴로 이동
    

### 2단계: OpenAI API 연결 추가 (NVIDIA NIM)

**"Connections"** 화면에서:

1. **OpenAI API** 섹션 찾기
    
2. **추가(+)** 버튼 클릭
    
3. 다음 정보 입력:
    

| 항목                  | 입력값                                         |
| ------------------- | ------------------------------------------- |
| **이름 (Name)**       | `NVIDIA NIM` (또는 원하는 이름)                    |
| **API URL**         | `https://integrate.api.nvidia.com/v1`       |
| **API 키 (API Key)** | `nvapi-`로 시작하는 발급받은 키 입력                    |
| **모델 목록 가져오기**      | "Fetch Models" 버튼 클릭 (자동으로 사용 가능한 모델 목록 로드) |

### 3단계: 사용할 모델 선택

모델 목록이 로드되면, 다음 중 원하는 모델을 선택하세요:

|모델명|특징|추천 용도|
|---|---|---|
|`meta/llama-3.1-70b-instruct`|가장 강력한 오픈소스 모델|구조화, 복잡한 분석|
|`meta/llama-3.1-8b-instruct`|가볍고 빠름|일상 대화, 간단한 작업|
|`mistralai/mixtral-8x7b-instruct`|뛰어난 추론 능력|코드 생성, 논리적 사고|
|`nvidia/nemotron-4-34b-instruct`|NVIDIA 자체 모델|한국어 포함 다국어 지원|

> 💡 **구조화 작업 추천**: `meta/llama-3.1-70b-instruct`가 가장 강력하지만, 무료 티어 제한(분당 40회)이 있으니 필요에 따라 8B 모델도 고려하세요.

### 4단계: 연결 테스트

1. **"Test Connection"** 버튼 클릭 → "Connection successful" 메시지 확인
    
2. **"Save"** 버튼 클릭하여 저장

## ⚠️ Open WebUI 주의사항

Open WebUI는 일반적으로 **SSE(Server-Sent Events)** 방식의 MCP 서버를 기대합니다. Vault as MCP는 **HTTP POST 요청**으로 동작하므로, Open WebUI가 이 방식을 지원하는지 확인해야 합니다.

### 만약 Open WebUI에서 연결이 안 된다면:

**대안 1: MCP Inspector로 먼저 테스트**

bash

복사

다운로드

npx @modelcontextprotocol/inspector
\# http://100.99.200.1:8765/mcp 입력
\# Headers에 Authorization: Bearer mcp-secure-token-2026-08-03 추가
\# Connect → 도구 목록 확인

**대안 2: HTTP-to-SSE 브릿지 사용**

bash

복사

다운로드

\# Vault as MCP를 SSE 방식으로 래핑
npx @modelcontextprotocol/sse-mcp-server \\
  \--command "curl" \\
  \--args "-X,POST,-H,Authorization: Bearer mcp-secure-token-2026-08-03,-H,Content-Type: application/json,-d,@-,http://100.99.200.1:8765/mcp"

## 🧪 Vault as MCP 도구 목록 확인 (선택)

MCP Inspector로 연결되면, Vault as MCP가 제공하는 도구들을 확인할 수 있습니다:

bash

복사

다운로드

\# 도구 목록 요청
curl \-X POST \-H "Authorization: Bearer mcp-secure-token-2026-08-03" \\
  \-H "Content-Type: application/json" \\
  \-d '{"jsonrpc": "2.0", "method": "tools/list", "params": {}, "id": 2}' \\
  http://100.99.200.1:8765/mcp

**예상 도구 목록**:

- `read_note` - 노트 읽기
- `write_note` - 노트 쓰기
- `list_notes` - 노트 목록
- `search_notes` - 노트 검색
- `delete_note` - 노트 삭제
- `rename_note` - 노트명 변경
