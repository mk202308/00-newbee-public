### 2\. `mcpo` 설치 스크립트 `install_mcpo.sh`

Bash

bash

```
#!/bin/bashset -e
sudo apt updatesudo apt install -y python3.12-venv python3-pip
rm -rf ~/mcpo-venvpython3 -m venv ~/mcpo-venvsource ~/mcpo-venv/bin/activate
pip install --upgrade pippip install mcpo==0.0.20 mcp==1.17.0# 1.17.3은 Python에 없음, 1.17.0이 mcpo 요구사항 >=1.17.0 만족하는 최적
pip show mcp mcpo~/mcpo-venv/bin/mcpo --help | head -20
deactivateecho "mcpo installed at ~/mcpo-venv/bin/mcpo (mcp 1.17.0 + mcpo 0.0.20)"
```

ini

```

[Service]User=ubuntuExecStart=/home/ubuntu/mcpo-venv/bin/mcpo --port 8002 --server-type "streamable-http" -- http://localhost:8001/mcpRestart=alwaysEnvironment=PYTHONUNBUFFERED=1# 메모리 제한 필요하면# MemoryMax=300M

### 5\. 검증 스크립트 `check.sh`

Bash

bash

```
#!/bin/bashset -e
echo "== mcp-obsidian health =="curl -s http://localhost:8001/health | python3 -m json.tool
echo -e "\n== mcpo openapi =="curl -s http://localhost:8002/openapi.json | python3 -m json.tool | grep operationId
