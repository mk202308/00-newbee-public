#### **2. 대안: `neuro-vault-mcp` 사용하기 (강력 추천)**

검색 결과에서 발견한 `neuro-vault-mcp`는 이 목적에 더욱 특화된 패키지입니다. **의미적 검색(Semantic Recall)** 과 **볼트 작업(Vault Operations)** 을 모두 제공하여, AI 에이전트가 검색뿐만 아니라 노트를 생성하거나 수정하는 것까지 가능하게 합니다[](https://socket.dev/npm/package/neuro-vault-mcp).


`obsidian-notes-mcp`[](https://www.npmjs.com/package/obsidian-notes-mcp?activeTab=dependents), `omem`[](https://www.npmjs.com/package/@kipachu/omem?activeTab=dependents) 등이 있습니다.

- **예시 도구**: **Agent**[](https://github.com/munroe153/obsidian-agent), **AI Study Buddy (LLM_Private_Teacher)**[](https://github.com/virbird/LLM_Private_Teacher), **Clawdian**[](https://github.com/keepnotes-ai/obsidian-clawdian) 등이 있습니다.

보내주신 화면은 Anthropic 등에서 제공하는 표준 **MCP Inspector** 대시보드입니다. 
현재 로컬 환경에서 MCP 서버들의 연결 상태를 테스트하고 검증할 수 있는 디버깅 UI가 정상적으로 실행되어 있습니다.

화면에 보이는 `filesystem-server-default`와 `everything-server-default`는 MCP 공식 테스트용 서버입니다.

### 현재 화면의 의미와 활용 방법

1. **STDIO 방식의 테스트**
    
    - 현재 등록된 서버들은 `npx -y ...` 명령어를 통해 표준 입출력(Standard I/O) 방식으로 동작하도록 설정되어 있습니다.
        
    - 각 카드 우측 상단의 스위치(Disconnected)를 켜면 MCP Inspector가 해당 명령어를 실행하고, 서버가 제공하는 툴(Tool)과 리소스(Resource) 목록이 정상적으로 뜨는지 웹 UI에서 실시간으로 확인할 수 있습니다.
        
2. **옵시디언 볼트 연동으로 확장하기**
    
    - 앞서 옵시디언에서 띄운 `Vault as MCP` 서버(`http://localhost:8765/mcp`) 또는 파일 시스템 서버를 이 Inspector에 추가하거나, 엔비디아 API 에이전트와 직접 연결하여 테스트를 이어갈 수 있습니다.
        

여기서 `filesystem-server-default` 카드의 **스위치를 켜서** 정상적으로 연결(Connected)되는지 테스트해 보시겠습니까?
