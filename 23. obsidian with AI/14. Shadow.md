# On-Demand Shadow - 00_newbee 공개 미러 최종 설계 v3 (B안: 자동 마스킹 + 사후 검사)

> 목표: 비공개 `00_newbee` 원본은 그대로 두고, 필요할 때만 `public-list.conf`에 지정한 폴더를 마스킹 후 `00_newbee-public` 공개 저장소로 내보낸다. 수동 실행이 원칙. cron 금지.

## 개요

```
[Mac] 편집 → push
       ↓
[Gitea: 00_newbee] 비공개 원본 729MB
       ↓
[OCI: /mnt/build-data/oci-vaults/00_newbee] 원본 clone
       ↓
[public-list.conf] /opt/shadow/public-list.conf - 공개 폴더 지정 (한 줄 한 폴더)
       ↓
[sync-shadow.sh] /opt/scripts/sync-shadow.sh
  - 파일명 기반 위험 파일 → [REDACTED] 치환
  - 내용 기반 자동 마스킹 (nvapi-, sk-, ghp_, AKIA, token, password 등) → Perl
  - 사후 검사 (남은 의심 패턴 리포트)
       ↓
[Gitea: 00_newbee-public] 공개 미러 - Orphan commit + Force push (히스토리 매번 초기화)
       ↓
[Claude] https://ocigit.duckdns.org/david/00_newbee-public/raw/branch/main/...
```

## 4단계: 동기화 스크립트 작성 (B안 - 자동 마스킹 + 사후 검사)

```bash
sudo tee /opt/scripts/sync-shadow.sh <<'SCRIPT'
#!/bin/bash
set -e
SOURCE="/mnt/build-data/oci-vaults/00_newbee"
SHADOW="/mnt/build-data/public-shadow/shadow"
LIST="/opt/shadow/public-list.conf"
LOG="/tmp/shadow-sync.log"
MASK_REPORT="/tmp/shadow-mask-report.txt"
POST_CHECK_REPORT="/tmp/shadow-postcheck.txt"
PUBLIC_URL="https://ocigit.duckdns.org/david/00_newbee-public"

log() { echo "[$(date '+%H:%M:%S')] $*" | tee -a "$LOG"; }
die() { log "❌ $*"; exit 1; }
> "$LOG"

log "[1/7] 원본 pull..."
cd "$SOURCE"
git pull --rebase --autostash --quiet

log "[2/7] 섀도우 초기화..."
mkdir -p "$SHADOW"
cd "$SHADOW"
if [ -d .git ]; then
  git fetch origin --quiet 2>/dev/null || true
else
  git clone "$PUBLIC_URL.git" . 2>/dev/null || true
fi
find "$SHADOW" -mindepth 1 -not -path "$SHADOW/.git*" -not -path "$SHADOW/.git/*" -exec rm -rf {} + 2>/dev/null || true

log "[3/7] 공개 폴더 복사..."
[ -f "$LIST" ] || die "public-list.conf 없음: $LIST"
FOLDERS=()
while IFS= read -r folder; do
  [ -z "$folder" ] && continue
  [[ "$folder" =~ ^[[:space:]]*# ]] && continue
  folder="$(echo "$folder" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//')"
  [ -z "$folder" ] && continue
  if [ ! -d "$SOURCE/$folder" ]; then
    log "  ⚠  없음: $folder"
    continue
  fi
  cp -r "$SOURCE/$folder" "$SHADOW/"
  FOLDERS+=("$folder")
  log "  ✅ $folder"
done < "$LIST"

[ ${#FOLDERS[@]} -eq 0 ] && log "⚠  공개 폴더 없음. README만 생성."

log "[4/7] 위험 파일 처리..."
find "$SHADOW" -type f \( -name "*.key" -o -name "*.pem" -o -name "*.p12" -o -name "*.pfx" -o -name "*.env" \) -exec sh -c 'echo "[REDACTED: filename filter]" > "$1"' _ {} \; 2>/dev/null || true

log "[5/7] 내용 자동 마스킹..."
> "$MASK_REPORT"
MASK_COUNT=0
mask_pattern() {
  local file="$1" pattern="$2" label="$3"
  local before after
  before=$(md5sum "$file" | cut -d' ' -f1)
  perl -i -pe "s/$pattern/\$1[REDACTED:$label]/gi" "$file" 2>/dev/null || true
  after=$(md5sum "$file" | cut -d' ' -f1)
  [ "$before" != "$after" ] && echo "$file|$label" >> "$MASK_REPORT" && MASK_COUNT=$((MASK_COUNT+1))
}

while IFS= read -r file; do
  mask_pattern "$file" '(nvapi-)[A-Za-z0-9_\-]{20,}' "NVIDIA_KEY"
  mask_pattern "$file" '(sk-)[A-Za-z0-9]{20,}' "OPENAI_KEY"
  mask_pattern "$file" '(ghp_)[A-Za-z0-9]{20,}' "GITHUB_TOKEN"
  mask_pattern "$file" '(fc-)[a-f0-9]{32}' "FIRECRAWL_KEY"
  mask_pattern "$file" '(AKIA)[0-9A-Z]{16}' "AWS_KEY"
  mask_pattern "$file" '(xoxb-)[A-Za-z0-9\-]{20,}' "SLACK_TOKEN"
  mask_pattern "$file" '(secret_)[A-Za-z0-9]{20,}' "NOTION_TOKEN"
  mask_pattern "$file" '(api[_-]?key[[:space:]]*[:=][[:space:]]*["\x27]?)[A-Za-z0-9_\-\.]{16,}' "API_KEY"
  mask_pattern "$file" '(token[[:space:]]*[:=][[:space:]]*["\x27]?)[A-Za-z0-9_\-\.]{20,}' "TOKEN"
  mask_pattern "$file" '(password[[:space:]]*[:=][[:space:]]*["\x27]?)[^"\x27[:space:]]{6,}' "PASSWORD"
  mask_pattern "$file" '(secret[[:space:]]*[:=][[:space:]]*["\x27]?)[A-Za-z0-9_\-]{12,}' "SECRET"
  if grep -q "BEGIN.*PRIVATE KEY" "$file" 2>/dev/null; then
    perl -i -0777 -pe 's/-----BEGIN[^-]*PRIVATE KEY-----.*?-----END[^-]*PRIVATE KEY-----/[REDACTED:PRIVATE_KEY]/gs' "$file" 2>/dev/null || true
    echo "$file|PRIVATE_KEY" >> "$MASK_REPORT"; MASK_COUNT=$((MASK_COUNT+1))
  fi
done < <(find "$SHADOW" -type f \( -name "*.md" -o -name "*.txt" -o -name "*.json" -o -name "*.yml" -o -name "*.yaml" \))

[ -s "$MASK_REPORT" ] && sort -u "$MASK_REPORT" | while IFS='|' read -r f l; do log "     ${f#$SHADOW/} [$l]"; done
log "  총 마스킹: $MASK_COUNT 건"

log "[6/7] 사후 검사..."
> "$POST_CHECK_REPORT"
POST_HITS=0
for pat in 'password[[:space:]]*[:=][[:space:]]*[^[:space:]\[]' 'secret[[:space:]]*[:=][[:space:]]*[^[:space:]\[]' 'BEGIN.*PRIVATE KEY'; do
  HITS=$(grep -rIEn "$pat" "$SHADOW" 2>/dev/null | grep -v "REDACTED" || true)
  [ -n "$HITS" ] && echo "$HITS" >> "$POST_CHECK_REPORT" && POST_HITS=$((POST_HITS+1))
done
[ "$POST_HITS" -eq 0 ] && log "  ✅ 사후 검사 통과" || log "  ⚠  잔존 의심 $POST_HITS 건 -> $POST_CHECK_REPORT"

log "[7/7] 공개 저장소 재작성 (orphan + force push)..."
if [ -s "$MASK_REPORT" ]; then
  MASK_SUMMARY=$(sort -u "$MASK_REPORT" | awk -F'|' '{n=$1; sub(".*/","",n); print "- `"n"` ["$2"]"}')
else
  MASK_SUMMARY="(없음)"
fi
cat > "$SHADOW/README.md" <<README
# 00_Newbee Public Shadow (On-Demand)

비공개 Obsidian 볼트의 임시 공개 미러. 히스토리는 매번 초기화됨.

**마지막 동기화**: $(date '+%Y-%m-%d %H:%M:%S KST')
**공개 폴더**:
$(for f in "${FOLDERS[@]}"; do echo "- \`$f\`"; done)
$( [ ${#FOLDERS[@]} -eq 0 ] && echo "(없음 - 전체 비공개 상태)")

## 자동 마스킹 ($MASK_COUNT 건)
$MASK_SUMMARY

## 사후 검사
$([ "$POST_HITS" -eq 0 ] && echo "✅ 이상 없음" || echo "⚠️ $POST_HITS 건 의심 - $POST_CHECK_REPORT 참조")

> \`[REDACTED:...]\`는 원본에만 존재.
> 원본: \`00_newbee\` (비공개)

## 사용법
\`\`\`
https://ocigit.duckdns.org/david/00_newbee-public/raw/branch/main/<폴더>/<파일>.md
\`\`\`
README

cd "$SHADOW"
rm -rf .git
git init -q
git branch -M main
git config user.email "shadow-bot@oci"
git config user.name "shadow-bot"
git remote add origin "$PUBLIC_URL.git"
git add -A
git diff --cached --quiet && log "변경 없음" && exit 0
git commit -q -m "shadow: $(date '+%Y-%m-%d %H:%M:%S') ${#FOLDERS[@]} folders, $MASK_COUNT masked"
git push -f origin main --quiet
log "✅ 완료: $PUBLIC_URL - ${FOLDERS[*]} / 마스킹 $MASK_COUNT"
SCRIPT

sudo chmod +x /opt/scripts/sync-shadow.sh
sudo chown ubuntu:ubuntu /opt/scripts/sync-shadow.sh
ls -l /opt/scripts/sync-shadow.sh
```

## 워크플로우 요약

```
[필요할 때]
1. shadow-edit → 공개 폴더 지정
2. shadow-sync → 마스킹 + 검사 + force push
3. Claude에게 URL 전달 → https://.../raw/branch/main/...
4. 완료 후 shadow-clear → 공개 중단 (README만 남음)

[자동 아님, 완전 수동 - cron 금지]
```

## 주의사항

1. **cron 금지**: 수동이 핵심. 자동화하면 "잠깐 공개"가 안 됨.
2. **히스토리**: orphan + force push로 매번 초기화. 그래도 오래 쓴 히스토리는 `git log`에 남을 수 있으니 주기적으로 `rm -rf .git && git init && push -f` 권장.
3. **민감 정보**: 파일명 필터 + Perl 내용 마스킹 + 사후 검사 3단계지만, 완벽하지 않음. 공개 전 `grep -riE "password|token|secret" /mnt/build-data/public-shadow/shadow --include="*.md"` 수동 확인 권장.
4. **토큰 보안**: `.git/config`에 토큰 포함 시 `chmod 600` 필수.
