루트 `/`는 11GB 남았고, Gitea가 있는 `/mnt/build-data`는 127GB 남았다. 디스크 풀 문제는 해결됐다.

### 결론 - 네 Git은 3곳에 있다

Code

```
1. Mac 원본: ~/00_Newbee/.git (343M)2. Gitea 중앙: /mnt/build-data/tailscale-gitea/data/git/repositories/david/00_newbee.git (332M)3. OCI 테스트 클론: ~/vault-test (아직 안 만들었으면 만들어야 함)
```

이제 마지막 단계만 남았다. `vault-test`를 검증하고 `/home/ubuntu/vault`로 교체하는 단계다.

Bash

```
cd ~rm -rf vault-testgit clone https://ocigit.duckdns.org/david/00_newbee.git vault-testdu -sh vault-testdu -sh vault-test/.gitdu -sh vault-test/.obsidian/ls -ld ~/vault 2>&1
```

2줄 숨겨짐

이 4개 결과 보여주면 바로 `/home/ubuntu/vault` 교체 명령어와 최종 `docker-compose.yml` 완성본을 준다.

# 방법 2 - git credential helper로 꺼내기
printf "protocol=https\nhost=ocigit.duckdns.org\n" | git credential-osxkeychain get

```
cd ~

# 토큰을 안전하게 변수에 저장 (입력해도 화면에 안 보임)
read -s TOKEN
# 여기에 붙여넣기하고 Enter
# 붙여넣기: 토큰 문자열 + Enter

echo "토큰 길이: ${#TOKEN} 자리 (40자리면 정상)"

# 변수로 clone (히스토리에 토큰 안 남음)

du -sh vault-test
du -sh vault-test/.git
du -sh vault-test/.obsidian/
ls -ld ~/vault 2>&1

# 확인 끝나면 변수 삭제
unset TOKEN
```
