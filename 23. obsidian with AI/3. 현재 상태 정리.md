

#### Step 1: `.gitignore` 최종본 (OCI용)

지금 `.gitignore` 너무 허술해. 이걸로 교체해야 OCI 구조에서 문제 안생긴다.

Bash

```
cd ~/00_Newbeecat > .gitignore <<'EOF'# macOS.DS_Store
# Obsidian - UI/캐시는 git 제외.obsidian/workspace.json.obsidian/workspace-mobile.json.obsidian/cache/.obsidian/hotkeys.json.obsidian/appearance.json.obsidian/graph.json
# Lumina AI - 절대 git에 올리면 안됨 (540MB + 매번 변경).obsidian/plugins/lumina/storage/.obsidian/plugins/lumina/data.json
# Obsidian Git - 자동 생성.obsidian/plugins/obsidian-git/data.json
# Syncthing.stfolder.stversions.stignore.trash.obsidian-trash/
# 대용량 바이너리 - Gitea 터짐 방지*.bin*.tibx*.tib*.img*.iso*.zip*.7z*.tar*.apk*.ttc*.itb*.dmg*.exe**/assets/*.bin**/assets/*.tibx
# 로그*.tmp*.logEOF
```

#### Step 2: 현재 Git에서 캐시 제거 (가벼운 정리)

Bash

```
cd ~/00_Newbee
# 지금 Git이 추적중인 lumina 파일들 제거git rm -r --cached .obsidian/plugins/lumina/storage/git rm --cached .obsidian/plugins/lumina/data.json 2>/dev/nullgit rm -r --cached .stversions 2>/dev/nullgit rm --cached "10. 공유기/05 Asus RT-AX3000(AX58U)/assets/memext4 (G).tibx" 2>/dev/nullgit rm --cached "10. 공유기/10 Xiaomi Router AX9000/assets/miwifi_ra70_firmware_d96a4_1.0.108.bin" 2>/dev/nullgit rm --cached "10. 공유기/10 Xiaomi Router AX9000/assets/miwifi_ra70_firmware_d96a4_1.0.108 1.bin" 2>/dev/null
git add .gitignoregit commit -m "chore: OCI 이전 - lumina 캐시 540MB, 바이너리 git 제외"git push
```

#### Step 3: .git 18GB 다이어트 (진짜 정리 - BFG)

이게 핵심. 히스토리에 박힌 18GB를 지워야 OCI clone이 300MB가 된다.

Bash

```
cd ~/00_Newbee
# 1. BFG 설치brew install bfg
# 2. 현재 Gitea에 백업 한번 더 push (안전용)git push origin main
# 3. 히스토리에서 20MB 이상 파일 전부 삭제bfg --strip-blobs-bigger-than 20M .git
# 4. 가비지 컬렉션 - 18GB -> 200MB로 줄어듦git reflog expire --expire=now --allgit gc --prune=now --aggressive
# 5. 확인du -sh .gitgit count-objects -vH
# 6. 강제 푸시 - Gitea 덮어쓰기 (주의!)git push --force origin main
```

`du -sh .git` 이 200MB 이하로 떨어지면 성공.
