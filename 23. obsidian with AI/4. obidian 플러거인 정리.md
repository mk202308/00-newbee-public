

### 지금 정확한 설치 상태 확인

터미널에서:

Bash

```
cd ~/00_Newbeels -1 .obsidian/plugins/ | sortdu -sh .obsidian/plugins/* | sort -hr
```

네가 전에 보여준 리스트 기준으로는 아직 있었거든:

Code

```
14M   fileorganizer2000543M  lumina
```

만약 `fileorganizer2000` 폴더가 여전히 있으면 Obsidian에서 저렇게 검색 말고 이렇게 삭제:

Obsidian > 설정 > 커뮤니티 플러그인 > 설치된 플러그인 목록에서

- 왼쪽 리스트에서 `File Organizer 2000` 찾아서 톱니바퀴 > Uninstall
- `Lumina` 찾아서 Uninstall (540MB 주범)

그리고 터미널에서 최종 청소:

Bash

```
cd ~/00_Newbeerm -rf .obsidian/plugins/fileorganizer2000/rm -rf .obsidian/plugins/lumina/du -sh .obsidian/plugins/ | tail -1du -sh .obsidian/# 582M -> 30~40MB로 떨어져야 정상
```

1줄 숨겨짐
